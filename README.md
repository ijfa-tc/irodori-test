# irodori-test

IJFA Learning Portal の「いろどり 課ごとのテスト（ウェブ版）」で使う音声と画像の置き場です。

- 公開URL：https://ijfa-tc.github.io/irodori-test/
- 音声：`X05-01.mp3` のように「X＝入門／Y＝初級1」＋「課-番号」。テストの問題文にある【X05-01】と同じ番号
- 画像：`（GoogleドライブのファイルID）.jpg`。「いろどりテスト 問題データ」シートの「画像」列のIDと同じ
- 問題と正解はここには置きません（正解はGoogle側のシートだけ）

## 出典

音声・イラスト：国際交流基金『いろどり 生活の日本語』（https://www.irodori.jpf.go.jp/）
